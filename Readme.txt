=================== Настройки! ========================
============================================================
- Добавляем Алкоголь в рецепты - меняет крафт медикаментов , нужен любой алкоголь ,этанол или брага
- Добавить извлечение гематогена из трупов? - Добавляет рецепт переработки трупов гуманоидов  на разделочные столы.
- Добавить строительство взрывоопасной двери?(Заминированная дверь)- Просто дверь что взорвётся если её разрушать(есть встроенная подсветка для защиты от тьмы, тесты показали что колонисты и землетрясения не приводят к взрыву)
- Сортировать ли мины по коробкам или просто оставить их лежать? - Изменение крафта и постройки мин. Позволяет заранее построить мины и затем их установить.
- Добавлять мягкие стены?- стены из ткани, мягкие, тёплые, горят.
- Добавить стены из светящегося камня? - Светятся, красивые.
- Колонна с девушкой и/или кошкой (выбор текстуры) позволяет выбрать текстуру.
- Добавить положительные эффекты для ковров? - в малом радиусе у ковриков будут положительные эффекты, баф температуры, изучения , медитации и тд
- Добавить хранилище токсичных пакетов? - просто бочки для отходов на палете, компактненько , миленько , токсичненько.
- Использовать алкоголь в лампе целителя? - алкоголь как топливо
- Отключить баг с лампой целителя?- отключает зону роста растений вокруг лампы
- Добавить Бомбардира в коконы жуков - в коконы будут добавлены жуки с дальней атакой 
- Добавить Бомбардира в рейды - добавляем бомбардира в рейды инсектоидов
- Добавить Королеву жуков в рейды - добавляем Королеву жуков в рейды инсектоидов
- Добавить Клещей в рейды - добавляем Клещей в рейды инсектоидов (Мелкие противные зажигательные жуки)
- Добавляете трансплантацию органов для андроидов? - расширяет возможность установки имплантов для андроидов
- Добавление излучения Rimatomics RTG? - Добавляем радиоактивное излучение вокруг РИТЭГа
- Добавление разнообразия в чайную продукцию? - Разнообразие чаю от ДедаСовета
- Добавление медового дерева? - легальный способ получить мёд
- Добавить рецепты для переработки ядарита в металл или светокамень? - всё сказано
- Добавить азотный хладагент? - холодильник, что работает на азоте и сильно понижает температуру
